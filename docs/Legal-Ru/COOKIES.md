## 2. Зачем этот документ

Магазины и пользователи часто ждут «cookie policy». Для Neptun ELTE правда такая:

- **локальное хранилище** приложения;
- **HTTP session** при работе с Neptun;
- **сторонние cookie** только если вы сами открыли внешний URL.

---

## 3. Это мобильное приложение

В репозитории **нет** цели `web/`. Нет маркетингового веб-UI с трекинговыми cookie. UI — Flutter на Android / iOS.

---

## 4. Технологии локального хранения

| Механизм | Обычно для |
|----------|------------|
| `flutter_secure_storage` | пароль, JWT, device/session cookie |
| `SharedPreferences` | username, настройки, флаги кэша |
| Кэш приложения | академические payload’ы |
| Система уведомлений | локальные напоминания |

Это **хранилище приложения**, не браузерные рекламные cookie.

## 5. Что хранится локально

См. [PRIVACY.md](PRIVACY.md). Примеры: тема, язык, кэш расписания/оценок/платежей, аватар профиля (base64), состояние входа. Автор не продаёт это рекламодателям.

## 6. HTTP cookie и сессия Neptun

Портал / HWEB: login + 2FA на `neptun.elte.hu`, OuterLogin / JWT на `hallgatoN`, device cookie в коде. Нужны **устройству** для API. Cookie на доменах Neptun задают **серверы университета**.

## 10. Как очистить

| Действие | Эффект |
|----------|--------|
| Logout | **JWT всегда стираются**; username может остаться |
| Пароль при logout | Очищается по умолчанию; **может остаться**, если включено «Запомнить пароль» (opt-in) |
| Фоновый keep-alive (опц.) | Только если включено в Настройках (~45 мин WorkManager / Background Fetch) |
| Очистка данных / удаление | Убирает prefs / secure storage приложения |
| Cookie сайтов в браузере | Чистить в браузере |
