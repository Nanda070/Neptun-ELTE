## 2. Что это за приложение

Клиент на **Flutter** для **ELTE Neptun**: расписание, предметы/оценки, сообщения, платежи, периоды.

- Хаб: **только ELTE** (`https://neptun.elte.hu`)
- После входа student API может идти на **HWEB** `hallgato1`…`hallgatoN.neptun.elte.hu`
- **Нет** собственного бэкенда приложения и **нет** push-сервера автора

Академические данные принадлежат инфраструктуре **ELTE / Neptun**. Эта политика — про **клиент**, не про серверы университета.

## 3. Данные на устройстве

Данные хранятся **локально**. У автора нет своей БД с вашими паролями Neptun или оценками.

### Секреты сессии

Обычно в **`flutter_secure_storage`**:

- пароль Neptun
- JWT access / refresh
- cookie / session-материал устройства, нужный клиенту

### Настройки и кэш

Обычно в **`SharedPreferences`** / файлах приложения:

- имя пользователя (код Neptun) для автозаполнения
- URL института / флаги API
- тема (Light / Dark), язык, шрифт, уведомления и т.п.
- кэш расписания, зачётки, платежей, периодов, почты, семестров
- **аватар профиля** (base64 JPEG из Neptun HWEB `UserInfo` / `GetUserAvatar`, только для drawer)

### Уведомления

Напоминания о парах, экзаменах, платежах и периодах — **локальные** (на устройстве).

### Опциональные загрузки с GitHub

Публичный JSON с ветки `main` репозитория проекта (raw), например список института, языковые паки RU/TR, метаданные тем. Запросы идут на **GitHub**, не на сервер автора.

### Ссылки

Баг-репорты и контакты могут открывать [nanda.is-a.dev](https://nanda.is-a.dev), Telegram, Discord, mailto — у этих сервисов свои политики.

## 6. Замечания по безопасности

- Секреты рассчитаны на **защищённое хранилище** устройства.
- HTTP-клиент принимает **любой** TLS-сертификат (обход битых кампусных сертификатов) → риск **MITM**. Лучше доверенные сети при логине.
- Logout / wipe сессии **всегда стирает JWT** (access/refresh); username может **остаться** для автозаполнения.
- **Пароль при logout:** по умолчанию очищается. Если включено **Запомнить пароль на этом устройстве** (Настройки, default **выкл**, **1.5.7** / ручной logout **1.5.10**), пароль может **остаться** в secure storage для prefill (**2FA вручную**). Выключение toggle очищает пароль.
- Опциональный **фоновый hallgato keep-alive** (Настройки, default **выкл**, **1.5.7+**): WorkManager / Background Fetch, ~**45 мин**, best-effort `GetNewTokens` — не трекинг/реклама.
- Неофициальный клиент — используйте осознанно рядом с официальным Neptun.

## 7. Хранение и выход

Данные живут на телефоне до logout, очистки данных приложения или удаления. JWT при выходе **всегда** сбрасываются; пароль — по правилу Remember-password выше. Серверы университета живут по своим правилам.
